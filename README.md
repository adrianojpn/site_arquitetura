# 🏛️ Elena Rostova — Arquitetura de Luxo & Interiores

> Web Application interativa de alto padrão para estúdio de arquitetura e design de interiores, inspirada na estética internacional Poliform.

🌐 **Site Online / Live Demo:** [https://adrianojpn.github.io/site_arquitetura/](https://adrianojpn.github.io/site_arquitetura/)

---

## 🎨 Sobre o Projeto

O **Site de Arquitetura Elena Rostova** foi concebido com uma linguagem visual contemporânea, minimalista e refinada. A experiência de navegação utiliza paletas neutras quentes (`#F7F5F0`, `#9E9080`, `#1A1918`), tipografia limpa, cantos arredondados, recortes chanfrados (notched cutouts) e micro-interações fluidas.

---

## 📱 Seções & Funcionalidades da Aplicação

### 1. 🖼️ **Hero Showcase (Banner Principal com Carrossel Automático)**
- Carrossel com transição suave de fotos de projetos de alta resolução.
- Indicador de progresso em barra sincronizada.
- Cartão overlay escuro com blur vítreo (glassmorphism) e botão de ação direta.

### 2. 🏛️ **Destaque Minimalista (Featured Showcase)**
- Layout exclusivo com cutout chanfrado inspirado em arquitetura italiana.
- Selo "Georgeus Interior", título e botão circular de expansão `↗`.

### 3. 💫 **Carrossel Interativo de Serviços (Interactive Services Slider)**
- Seção em tom taupe (`#9E9080`) com rolagem por **arraste de mouse no desktop** ou **deslize de dedo no mobile**.
- Transição com *fade* suave de textos (Design de Interiores, Projetos Arquitetônicos, Gestão de Obra, Consultoria, Curadoria).
- Botões circulares de navegação e contador de progresso sincronizado.

### 4. 📐 **Coleção Autoral & Galeria de Portfólio (Portfolio Grid)**
- Galeria de projetos (*Residencial, Comercial, Interiores*).
- Filtros interativos por categoria.
- **Modal Detalhado por Projeto:** Janela popup em tela cheia exibindo fotos em alta resolução, especificações técnicas (m², localização, ano), conceito arquitetônico e link direto para WhatsApp com mensagem pré-preenchida.

### 5. ✍️ **Perfil da Arquiteta & Pilares de Autoridade (About Section)**
- Apresentação da fundadora Elena Rostova (CAU A-149.204).
- Pilares de design: *Bioclimática & Luz Natural*, *Proporção Áurea*, *Marcenaria Autoral*.

### 6. 🛠️ **Serviços com Entregáveis (Services Section)**
- 4 cards de serviços detalhados com checklist dos entregáveis inclusos.
- Integração de orçamento direto via WhatsApp.

### 7. ✉️ **Agendamento & Atendimento (Contact CTA)**
- Bloco obsidian escuro ("Engage with Us in Conversation").
- Agendamento de reuniões e consultas presenciais ou online.

## 🛠️ Tecnologias Utilizadas

- **Framework:** React Native Expo (Web Engine)
- **Roteamento:** Expo Router (`expo-router`)
- **Linguagem:** TypeScript
- **Ícones:** Lucide React Native (`lucide-react-native`)
- **Deploy:** GitHub Pages (`gh-pages`)

---

## 💻 Como Rodar o Projeto Localmente

```bash
# 1. Clonar o repositório
git clone https://github.com/adrianojpn/site_arquitetura.git

# 2. Entrar na pasta do projeto
cd site_arquitetura

# 3. Instalar as dependências
npm install

# 4. Rodar o servidor de desenvolvimento Web
npm run web
```

---

## 🚀 Como Atualizar e Fazer Deploy no GitHub Pages

Para publicar novas alterações no ar, execute o comando:

```bash
npm run deploy
```
